Predict Student Math Performance Using Machine Learning. This web application uses a trained machine learning model to predict a student's Math Score based on academic and demographic information.

Enter the required details and generate an instant prediction with a clean, simple interface.

How it works The model analyzes gender, race/ethnicity, parental education, lunch type, test preparation course, reading score, and writing score to estimate student performance.
