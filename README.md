# Student Performance Indicator

End-to-end machine learning project for predicting a student's Math Score from demographic and academic inputs.

## What it does

- Predicts student Math Score using a trained regression pipeline
- Provides a Flask web app with a landing page and prediction form
- Uses preprocessing, feature engineering, and model selection steps

## Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- XGBoost

## Run the app

1. Activate your environment.
2. Run `python app.py` from the project root.
3. Open the local Flask URL shown in the terminal.
